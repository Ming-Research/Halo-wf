Decision: Lua-to-Lua calls, `pcall`, `error` and host calls use the VM's own value stack and frame records, never the machine stack, while Lua code that a metamethod or a library function calls back runs as a nested activation refused with "C stack overflow" at PUC's limit of 200 nested calls, because a script's depth then cannot exhaust the host's stack and a script that reaches the limit gets Redis's error ([VM design, calls](../../research/investigations/halo/VM.md#3-calls)), instead of recursing on the machine stack for every Lua call.
