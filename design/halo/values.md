Decision: A Lua value is a tagged enum of nil, the two booleans, an `f64` number, a builtin ID, or a `u32` index into the slab of its kind (string, table or closure), 16 bytes as PUC Lua 5.1's `TValue`, because `match` lowering and the collector then work on the enum's own types while moving the same bytes as the reference interpreter, instead of NaN boxing, which would decode every tag by hand with `reinterpret` outside those types ([VM design, values](../../research/investigations/halo/VM.md#1-values)).

Decision: A slab index carries no generation; each cell keeps a checked `live` flag, because a precise collector never leaves an index to a freed cell reachable, and a generation would add a load and a compare to every table and string access, instead of the generational handles of the [E1 heap experiment](../../research/experiments/halo-heap/RESULTS.md).
