Decision: A host extends Halo through one `Host<E>` interface whose call receives the host's environment, the VM and the stack window of its arguments, and returns results, raises, or stops the run with the stack intact, because a host's functions need its own state and a host must be able to stop a script at a clean point and restart it, instead of registering closures over host state inside the engine ([VM design, embedding](../../research/investigations/halo/VM.md#6-embedding)).
