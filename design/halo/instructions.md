Decision: An instruction is one variant of a cell enum with its operands as fields, registers and constant indexes as `u8` and a target or wide index as `u32`, with Lua's register-or-constant operands split into separate variants and each compare or test fused with the jump that follows it, because every operand is then one load and a branch costs one dispatch, and dispatch count dominates an interpreter's time ([interpreter inputs](../../research/investigations/halo/DESIGN.md#interpreter-inputs)), instead of Lua 5.1's packed 32-bit words decoded by shifts and masks on every access ([VM design, instructions](../../research/investigations/halo/VM.md#4-instructions)).

Decision: A `u8` operand needs no comparison: the stack keeps 256 slots above every frame's `base` and each script's constant pool is padded with 256 nils past every prototype's `kbase`, a prototype's 257th and later constants load through `LoadKx` with one comparison, and a verifier run once per script checks jump targets, registers and the final return for Lua-level correctness without its facts reaching the dispatch, because the windows are facts the dispatch already carries, instead of comparing every operand index at run time.
